### Maintainer notes

RDP sharing of an existing physical monitor through a native Omarchy panel.
Capabilities: explicit terminal installer, package management, privileged package
installation, checksum-pinned remote source build and marked user-service management.
Runtime is unprivileged; no firewall or sudoers modifications. Credentials are
stored outside the checkout in owner-only files. No passwords in .rdp exports.
Windows and Android are owner-tested; audio mirroring and logout/login passed.
Mac is expected compatible but untested. Android audio delay was reported.
See SECURITY.md and docs/RELEASE-REVIEW.md for scope, evidence and limits.
Preview assets render the actual plugin using sample data.
